# Store Listing and Screenshot Plan

## App Name

StitchSense Pro

## Subtitle / Short Description

AI pattern help and library sync

## Full Description Draft

StitchSense Pro keeps your pattern library, AI helper, rewrites, and stitch analysis together across web and mobile.

Save patterns, open them on the go, ask questions when instructions get confusing, rewrite tricky sections into clearer language, and use Stitch Vision to analyse stitch photos when you need another pair of eyes.

Built for makers who want less friction between pattern, project, and help.

Core features:
- Pattern library sync across web, iOS, and Android.
- AI chat for saved patterns.
- Rewrite tools for confusing instructions.
- Stitch Vision photo analysis.
- Private pattern file storage with signed access.
- Subscription access synced across devices.

## Screenshot Production Notes

- Use realistic pattern names but avoid copyrighted pattern content unless you own it or have permission.
- Do not include real user email addresses.
- Avoid showing private API URLs, tokens, or admin-only screens.
- Show subscription pricing exactly as configured in the store at release time.
