# StitchSense Pro Privacy Policy Draft

Last updated: 2026-06-16

This is a working draft for review before public release. It should be checked by the business owner and, if needed, a qualified legal adviser before publishing.

## Who We Are

StitchSense Pro helps users store knitting/crochet pattern files, ask AI questions about patterns, generate pattern rewrites, and analyse stitch photos.

Contact: `[support email/contact URL to add]`

## Information We Collect

Account information:
- Email address.
- Display name.
- Account identifiers used to connect web, iOS, Android, WordPress, and subscription records.

User content:
- Pattern files uploaded by the user.
- Pattern metadata, titles, summaries, and notes.
- Chat messages, rewrite prompts, rewrite outputs, and Stitch Vision image inputs.
- Optional Ravelry connection metadata if the user connects Ravelry.

Subscription and entitlement information:
- Subscription provider, subscription status, plan, renewal/expiry timestamps, and transaction identifiers from Stripe, Apple, Google Play, or RevenueCat.
- Admin-granted complimentary access records where applicable.

Technical and diagnostic information:
- API logs needed for security, reliability, fraud prevention, debugging, and abuse prevention.
- App analytics and error events generated by StitchSense Pro.

We do not intentionally collect precise location, contacts, advertising IDs, or third-party advertising tracking data as part of the MVP.

## How We Use Information

We use information to:
- Create and secure user accounts.
- Sync the user’s pattern library across web, iOS, and Android.
- Store and display uploaded pattern files.
- Run AI-powered pattern chat, rewrite, upload analysis, and Stitch Vision features.
- Manage subscriptions, free trials, and admin-granted Pro access.
- Provide customer support.
- Monitor service health, prevent abuse, and improve reliability.

## AI Processing

When a user asks StitchSense Pro to analyse, rewrite, or discuss a pattern, relevant prompts, files, images, and metadata may be sent to server-side AI workflows. Mobile apps and WordPress do not call n8n directly; requests go through the StitchSense API for authentication, entitlement checks, and logging.

## Third-Party Service Providers

StitchSense Pro may use:
- Object storage provider for private pattern files.
- PostgreSQL database hosting.
- n8n workflow automation.
- AI/LLM providers behind n8n workflows.
- Stripe for web subscription checkout.
- Apple App Store and Google Play for mobile subscriptions.
- RevenueCat for mobile subscription status and webhooks.
- Ravelry API if the user chooses to connect Ravelry.

Payment card details are handled by payment providers and app stores. StitchSense Pro stores subscription status and provider identifiers, not full card details.

## Sharing

We do not sell user personal data. We share data only with service providers needed to operate the app, process subscriptions, provide AI features, maintain security, or comply with law.

## Data Retention

We keep account, pattern, chat, rewrite, and subscription records while the account is active. Users can request export or deletion through app/account tools or support. Some records may be retained where required for security, fraud prevention, tax, accounting, dispute handling, or legal compliance.

## User Choices

Users can:
- Export account data.
- Delete account data.
- Disconnect optional integrations where supported.
- Cancel paid subscriptions through Stripe, Apple, or Google Play depending on purchase source.

## Security

StitchSense Pro uses authenticated API access, server-side workflow secrets, private object storage with signed file URLs, and scoped admin entitlement tools. No system can be guaranteed perfectly secure, but the app is designed to reduce exposure of workflow secrets and private files.

## Children

StitchSense Pro is not intended for children under 13. If child-directed use is planned later, this policy and store declarations must be revisited before release.

## International Users

Users may access StitchSense Pro from different countries. Data may be processed in the country where hosting, workflow, AI, payment, or storage providers operate.

## Changes

We may update this policy as StitchSense Pro evolves. Material changes should be published with an updated date.
