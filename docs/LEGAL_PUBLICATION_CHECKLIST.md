# StitchSense Legal Publication Checklist

Use this before store submission and public beta. Final wording must be approved by the business/legal owner before publication.

## Required Public URLs

| URL | Required content | Status | Evidence / notes |
| --- | --- | --- | --- |
| Privacy policy | Data collection, sharing, deletion, retention, support contact |  |  |
| Terms of service | Account rules, acceptable use, liability, service availability |  |  |
| Subscription terms | Price, renewal, cancellation, trial, restore, store-managed billing |  |  |
| Support/contact | Monitored support route |  |  |
| Account deletion | User deletion path and subscription-management guidance |  |  |

## Consistency Checks

| Check | Result | Evidence / notes |
| --- | --- | --- |
| Privacy policy matches `docs/PRIVACY_DATA_SAFETY_WORKSHEET.md` |  |  |
| Store listings use the same support/privacy URLs |  |  |
| Account deletion wording matches API/app behaviour |  |  |
| Subscription wording says Apple/Google manage cancellation |  |  |
| Subscription wording excludes any public mobile lifetime plan unless separately launched |  |  |
| Manual developer/support access is described, if mentioned, as admin-granted access rather than a public store product |  |  |
| Data retention wording matches `docs/DATA_RETENTION_AND_DELETION_POLICY.md` |  |  |
| No unpublished pricing, secret endpoint, or internal contact appears publicly |  |  |
