# StitchSense Support Macro Library

Use these approved starter responses during beta, store review, and public rollout. Keep messages short, ask for support codes rather than private content, and do not request passwords, payment-card details, or full private pattern files.

## Identity And Login

| Situation | Macro |
| --- | --- |
| Cannot sign in | Please try signing in again and send the support code shown in the app if it appears. Do not send your password. |
| Session expired | Please sign in again. If the same message returns, send the support code and the approximate time it happened. |
| WordPress/Ravelry link issue | Please confirm which connected account you expected to use. Do not send account passwords; we only need the support code and the time of the attempt. |

## Patterns And AI

| Situation | Macro |
| --- | --- |
| Upload failed | Please send the support code, file type, and approximate file size. Do not send the pattern file unless support explicitly provides a secure upload route. |
| Chat/rewrite wrong pattern | Please stop using that chat and send the support code, pattern name, and time of the message. We treat wrong-pattern reports as urgent. |
| Paid Ravelry pattern content missing | StitchSense can import paid-pattern metadata from Ravelry, but it cannot access paid pattern content unless you upload your owned source file. |
| Stitch Vision issue | Please tell us whether you used camera or photo library and send the support code. Do not send images containing private information. |

## Billing

| Situation | Macro |
| --- | --- |
| Purchase not active | Please tap Restore Purchase in the app. If access is still missing, send the support code and confirm whether the purchase was through Apple or Google. |
| Manual/developer access missing | Please send the support code and the email address used for StitchSense. Do not purchase through the store while we check the admin-granted access record. |
| Cancellation question | App Store and Google Play subscriptions are managed through your Apple or Google account. StitchSense will keep access until the store-reported paid-through date. |
| Refund/revocation | Refunds and revocations are handled by Apple or Google. Once the store updates the subscription status, StitchSense will refresh access accordingly. |

## Privacy And Deletion

| Situation | Macro |
| --- | --- |
| Data export/deletion | You can use the in-app account/data tools for export or deletion. If anything looks wrong, send the support code and do not include private pattern contents. |
| Cross-user concern | Thank you for reporting this. Please stop using the affected screen and send the support code and time it happened. We will treat this as urgent. |
| Crash/startup failure | Please reopen the app once. If it repeats, send the device model, iOS/Android version, app version, and the approximate time it happened. |

## Escalation Notes

- Escalate cross-user access, wrong-pattern AI context, data loss, billing entitlement mismatch, and startup crash reports immediately.
- Preserve support codes, timestamps, and app versions.
- Keep raw customer content out of internal issue titles and screenshots.
